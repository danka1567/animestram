# EarnVids API Reference Documentation
# API Key: 47202gy09k73xaina8y8t

API Base URL: https://earnvidsapi.com/api

Endpoints:
1. Account Info: GET https://earnvidsapi.com/api/account/info?key={key}
2. Account Stats: GET https://earnvidsapi.com/api/account/stats?key={key}&last={days}
3. Get Upload Server: GET https://earnvidsapi.com/api/upload/server?key={key}
4. Upload File to Server: POST {upload_server_url} (multipart form: key, file, file_title, file_descr, snapshot, fld_id, cat_id, tags, file_public, file_adult, html_redirect)
5. Upload by URL (Remote): GET https://earnvidsapi.com/api/upload/url?key={key}&url={url}&fld_id={fld_id}&cat_id={cat_id}&file_public={file_public}&file_adult={file_adult}&tags={tags}
6. Upload Subtitle: POST https://earnvidsapi.com/api/upload/sub (key, file_code, sub_lang, sub_file)
7. File Info: GET https://earnvidsapi.com/api/file/info?key={key}&file_code={file_code}
8. File Edit: GET https://earnvidsapi.com/api/file/edit?key={key}&file_code={file_code}&file_title={file_title}...
9. File List: GET https://earnvidsapi.com/api/file/list?key={key}&fld_id={fld_id}&page={page}&per_page={per_page}
10. File Direct Link: GET https://earnvidsapi.com/api/file/direct_link?key={key}&file_code={file_code}&ip={ip}&q={q}&hls={hls}
11. File Clone: GET https://earnvidsapi.com/api/file/clone?key={key}&file_code={file_code}&file_title={title}&fld_id={fld_id}
12. File Delete: GET https://earnvidsapi.com/api/file/delete?key={key}&file_code={file_code}
13. Deleted Files: GET https://earnvidsapi.com/api/file/deleted?key={key}&last={hours}
14. File DMCA: GET https://earnvidsapi.com/api/file/dmca?key={key}&last={hours}
15. Folder List: GET https://earnvidsapi.com/api/folder/list?key={key}&fld_id={fld_id}&files=1
16. Folder Create: GET https://earnvidsapi.com/api/folder/create?key={key}&name={name}&parent_id={parent_id}&descr={descr}
17. Folder Edit: GET https://earnvidsapi.com/api/folder/edit?key={key}&fld_id={fld_id}&name={name}&parent_id={parent_id}&descr={descr}
18. Folder Delete: GET https://earnvidsapi.com/api/folder/delete?key={key}&fld_id={fld_id}
19. File Encodings: GET https://earnvidsapi.com/api/file/encodings?key={key}&file_code={file_code}
20. File URL Uploads: GET https://earnvidsapi.com/api/file/url_uploads?key={key}&file_code={file_code}
21. File URL Uploads Actions: GET https://earnvidsapi.com/api/file/url_actions?key={key}&restart_errors=1|delete_errors=1|delete_all=1|delete_code={codes}
